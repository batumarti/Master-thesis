---------------------------------------------
SECONDARY STRUCTURE ANALYSIS - DSSP
---------------------------------------------
This procedure utilizes the GROMACS DSSP implementation to calculate the secondary structure of a protein along a molecular dynamics trajectory. Following the extraction of the structural assignments, a Python script is used to generate occurrence bar plots, and command-line utilities are employed to isolate and inspect specific alpha-helical ('H') content.

## REQUIRED FILES:
Ensure the following files are available in the working directory:

- md_prot.tpr --> GROMACS run input file containing the system topology.
- center_traj.xtc --> Centered molecular dynamics trajectory to analyze.
- plot_occupancy_bars.py --> Python script to plot the secondary structure occurrences.

## EXECUTION

1. Calculate the secondary structure using GROMACS DSSP:
`gmx_mpi dssp -s md_prot.tpr -f center_traj.xtc -num scount.xvg -hmode dssp -o dssp_analysis.dat -dt 100`

2. Generate the occurrence bar plots:
```
module load python
python plot_occupancy_bars.py -l <1_or_2> -r <ATG8_range> <LIR_range>
```
3. Extract the secondary structure assignments for the second chain and search for alpha-helical (`H`) occurrences:
```
cut -d`=` -f2 dssp_analysis.dat > dssp_lir.dat
grep H dssp_lir.dat
```
## OUTPUT

The execution of these commands will generate the following files:
- dssp_analysis.dat --> Raw DSSP output containing the secondary structure assignments for each frame.
- scount.xvg --> GROMACS output tracking the number of residues in each secondary structure conformation over time.
- dssp_lir.dat --> Processed text file containing the extracted secondary structure sequences for the LIR chain.
- occupancy_LIR.png & occupancy_ATG8.png --> Graphical representations of the secondary structure occurrences generated by the Python script.
